مهارة : CSS

CSS (Cascading Style Sheets) هي لغة تُستخدم لتصميم وتنسيق صفحات الويب. تتحكم في الألوان، الخطوط، التخطيط، والمظهر العام للعناصر. تُكتب عبر قواعد تتضمن مُحددات (Selectors) وخصائص (Properties) وقيم (Values). يمكن إضافتها داخل HTML (inline)، في ملف منفصل، أو داخل وسم . تتيح التصميم التكيفي لتناسب الأجهزة المختلفة.
