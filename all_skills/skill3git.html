مهارة : GIT

Git: نظام تحكم بالإصدارات لتتبع التغييرات في الكود. يسمح بالعمل الجماعي، إدارة النسخ، واستعادة التعديلات. الأوامر الأساسية: git init: إنشاء مستودع. git add: إضافة تغييرات. git commit: حفظ التغييرات. git push/pull: رفع/سحب التغييرات من/إلى مستودع بعيد. git branch: إدارة الفروع.
